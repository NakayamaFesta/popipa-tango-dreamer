# Poppin'Party 歌词单词站（Popipa 单词机）

从 Poppin'Party 歌词里学日语单词的静态网页。

🌐 在线体验：https://nakayamafesta.github.io/popipa-tango-dreamer/

已部署到GitHub，欢迎大家测试！

## 为什么做这个

做这个单词机最开始是为了备战**广州 Poppin'Party Only 展的唱歌环节**，想跟着歌词熟练跟唱。我觉得比“跟着唱”更重要的，是能抛开中文翻译，亲自读懂歌词的意思，直接接收到 Poppin'Party 的歌词里想传达的心意。

希望这个项目能帮助大家针对性地背单词，让 Poppin'Party 的歌词里想传达的心意，能直接传到每个人的心里。

所以我希望这个单词机不是让你死记硬背，而是帮你：

- 看懂歌词里的日语词
- 听出发音、记住意思
- 最后能不用翻译，直接感受到 Popipa 在唱什么

也正因为这个目标，它对使用者**有一定的基础要求**——不需要很高，但不能完全零基础。

我选过两次日语课，分别学了两版教材的这些单元：

- 本科阶段：**《新版中日交流标准日本语 初级 上册》**，学到了第 4 单元（第 13～16 课）
- 研究生阶段：**华东理工大学出版社《新编日语教程》第一册**，学到了第 2 单元第 6 课

后面给大家定的“推荐练度”就是参照我自己的学习进度来标的。

另外，如果你在使用过程中发现问题——尤其是**单词读音和歌曲里的实际读法不一致**的，欢迎来 GitHub 提交 issue。其他功能建议也欢迎提，希望能方便到更多的人。

## 功能

- 按歌曲学习歌词中的单词
- 单词卡翻转：日文 → 罗马音 / 假名 / 中文释义
- 单词发音：优先播放 `audio/words/*.mp3`，缺失时回退浏览器日语 TTS
- 间隔复习：1 / 3 / 7 天
- 歌词模式：查看歌词并统计该曲词汇掌握度
- 测验模式
- 进度导出 / 导入 / 连接本地文件备份

## 怎么用

1. 打开网页（本地直接打开 `index.html`，或部署后访问在线地址）
2. 在“单词模式”里，先学今天的生词 / 复习到期单词
3. 在“歌词模式”里选一首 Poppin'Party 的歌，按歌背词
4. 点卡片翻面看罗马音、假名和释义；动词卡会列出歌词中实际出现的语法形态
5. 答对 / 答错后，系统会按间隔复习安排下次出现时间
6. 进度默认保存在当前浏览器；需要备份可以用“导出进度” / “导入进度”，或“连接 学习进度.json”

## 推荐练度 / 适合谁

这个工具不是完全零基础入门用的，但加了罗马音之后，最低门槛已经降到“会读罗马音”。建议尽量达到下面的“推荐练度”，至少也要满足“最低要求”。

### 推荐练度

- 熟练掌握五十音图
- 熟悉日语单词和句子的发音规则
- 至少达到以下任一教材范围：
  - **《新版标日 初级上册》学到第 4 单元（第 13～16 课）** —— 这是作者本科上课学过的范围
  - **华东理工《新编日语教程》第一册至少学到第 2 单元第 6 课** —— 这是作者研究生上课学过的范围

### 最低要求

- 认得罗马音的拼读规则（能看着卡片上的 romaji 读出假名/发音）
- 了解基本发音规则（长音、促音、拗音等，可借助罗马音跟读）
- 最好已经“**去成田机场接过小李**”（也就是学完标日初级上册第 1 单元“小李赴日”，第 1～4 课）

> 换句话说：会看罗马音、知道基本句型、能读懂 Poppin'Party 歌词里的常见 N5 词汇，用起来会更顺。

### 使用前需要知道

- **有罗马音**：卡片翻面后会在假名上方显示罗马音，方便五十音图还没完全背熟时跟读。
- **动词会标注歌词实际形态**：词条以辞书形（如「食べる」「見つける」）收录，卡片背面会用表格列出歌词里实际出现的活用形、语法说明、中文翻译和出现歌曲（如「食べて／て形／吃，然后……／某首歌」），方便直接对照歌词。
- **词表不限于教材**：歌词里有很多教材没教过的词，但只要你有上面说的基础日语骨架，背起来会轻松很多。
