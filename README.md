# Poppin'Party 歌词单词站（Popipa 单词机）

从 Poppin'Party 歌词里学日语单词的静态网页。

## 为什么做这个

我做这个单词机，最开始是为了**广州 Poppin'Party Only 展的唱歌环节**，想跟着歌词熟练跟唱。

但后来觉得，比“跟着唱”更重要的，是希望**大家能抛开中文翻译，亲自读懂歌词的意思**，
让 Poppin'Party 的歌词里想传达的心意，能直接传到每个人的心里。

所以我希望这个单词机不是让你死记硬背，而是帮你：

- 看懂歌词里的日语词
- 听出发音、记住意思
- 最后能不用翻译，直接感受到 Popipa 在唱什么

也正因为这个目标，它对使用者**有一定的基础要求**——不需要很高，但不能完全零基础。

我选过两次日语课，分别学了两版教材的这些单元：

- 本科：**《新版中日交流标准日本语 初级 上册》**，学到了第 4 单元（第 13～16 课）
- 研究生：**华东理工大学出版社《新编日语教程》第一册**，学到了第 2 单元第 6 课

所以后面给大家定的“推荐练度”，就是参照我自己的学习进度来标的。

## 功能

- 按歌曲学习歌词中的单词
- 单词卡翻转：日文 → 假名 / 中文释义
- 单词发音：优先播放 `audio/words/*.mp3`，缺失时回退浏览器日语 TTS
- 间隔复习：1 / 3 / 7 天
- 歌词模式：查看歌词并统计该曲词汇掌握度
- 测验模式
- 进度导出 / 导入 / 连接本地文件备份

## 怎么用

1. 打开网页（本地直接打开 `index.html`，或部署后访问在线地址）
2. 在“单词模式”里，先学今天的生词 / 复习到期单词
3. 在“歌词模式”里选一首 Poppin'Party 的歌，按歌背词
4. 点卡片翻面看假名和释义，点喇叭听发音
5. 答对 / 答错后，系统会按间隔复习安排下次出现时间
6. 进度默认保存在当前浏览器；需要备份可以用“导出进度” / “导入进度”，或“连接 学习进度.json”

## 推荐练度 / 适合谁

这个工具不是零基础入门用的。建议至少达到下面的“推荐练度”再用，最低也要满足“最低要求”。

### 推荐练度

- 熟练掌握五十音图
- 熟悉日语单词和句子的发音规则
- 至少达到以下任一教材范围：
  - **《新版标日 初级上册》学到第 4 单元（第 13～16 课）** —— 这是作者本科上课学过的范围
  - **华东理工《新编日语教程》第一册至少学到第 2 单元第 6 课** —— 这是作者研究生上课学过的范围

### 最低要求

- 熟练掌握五十音图
- 熟悉日语单词和句子的发音规则
- 已经“**去成田机场接过小李**”（也就是学完标日初级上册第 1 单元“小李赴日”，第 1～4 课）

> 换句话说：会五十音、知道基本句型、能读懂 Poppin'Party 歌词里的常见 N5 词汇，用起来会更顺。

### 使用前需要知道

- **没有罗马音**：这个单词机最初是作者做给自己用的，所以没有加罗马音，默认你已经能读假名。
- **动词多为“辞书形”（る形）**：歌词提取时，很多动词 / 动词短语会被还原成原形（如「食べる」「見つける」），
  但歌词里实际出现的可能是「食べて」「見つけた」「見つけない」等活用形。
  所以需要你掌握动词的**て形 / た形 / ない形 / ます形**等基础变形，才能把歌词中的词和词表对应起来。
- **词表不限于教材**：歌词里有很多教材没教过的词，但只要你有上面说的基础日语骨架，背起来会轻松很多。
